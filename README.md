# Drum Machine - freeCodeCamp Project

A fully functional drum machine built with React as part of the **freeCodeCamp Front End Development Libraries** certification.

## ✨ Features

- 9 clickable drum pads
- Keyboard support (Press Q, W, E, A, S, D, Z, X, C)
- Real-time display showing the name of the played sound
- High-quality audio samples
- Responsive and visually appealing design
- Clean audio handling (reset playback position)

## 🛠 Technologies Used

- **React.js** (Functional Components + Hooks)
- `useState` and `useEffect`
- HTML5 Audio API
- JavaScript (ES6+)
- CSS (via App.css)
